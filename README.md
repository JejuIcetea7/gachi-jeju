# 같이 가는 제주

같이 가는 제주는 이동약자와 동반자가 제주 여행을 계획할 때, 관광지까지 어떻게 이동할지와 도착 후 어떤 시설과 동선을 확인해야 할지를 함께 보여 주는 AI 여행 플래너입니다. 날짜, 이동수단, 보조기구, 필요한 시설을 선택하거나 채팅으로 알려 주면 일정을 만들고, 후속 요청으로 일정이나 숙소를 바꿀 수 있습니다.

## 주요 기능

| 기능 | 화면에서 확인할 수 있는 내용 |
|---|---|
| 대화형 일정 | 방문지, 체류시간, 운영시간과 휴무일을 반영한 날짜별 일정 |
| 이동 경로 | 자동차·도보·대중교통 경로, 소요시간과 버스 승하차 안내 |
| 방문 전 확인 | 대표 사진, 장애인 화장실·주차구역, 경사·단차 등 장소별 정보 |
| 숙소 선택 | 숙박일별 숙소 후보를 선택하고 전후 이동 경로와 시간을 재계산 |
| 일정 공유 | 전체 일정 PDF 다운로드와 이메일 첨부 발송 |

시설을 이용할 수 있는지 확인이 필요한 경우, 일정표에 방문 전에 확인할 항목을 표시합니다.

## 로컬 실행

Python 3.12와 Node.js 24를 사용합니다. 아래 명령은 Windows CMD에서 프로젝트 루트를 기준으로 실행합니다.

```cmd
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
npm ci
npm --prefix frontend ci
if not exist .env copy .env.example .env
```

| 설정 파일 | 입력할 환경변수 |
|---|---|
| `.env` | `OPENAI_API_KEY`로 일정 생성에 사용할 OpenAI API 키를 설정합니다. |
| `.env` | `KAKAO_REST_API_KEY`로 백엔드 경로 조회에 사용할 카카오 REST API 키를 설정합니다. |
| `frontend/.env.local` | `VITE_KAKAO_MAP_KEY`로 지도에 사용할 카카오 JavaScript 키를 설정합니다. 카카오 앱의 허용 도메인에 `http://localhost:5173`을 등록합니다. |

관광지 SQLite DB와 사진 주소 목록은 저장소에 포함되어 있습니다.
이메일 발송을 사용하려면 프로젝트 루트의 `.env`에 SMTP 설정을 추가합니다. 필요한 변수는 [`.env.example`](.env.example)에서 확인할 수 있습니다.

```cmd
.venv\Scripts\activate.bat
npm run dev
```

브라우저에서 [여행 플래너](http://localhost:5173)를 엽니다. 백엔드가 실행 중인지 확인하려면 [상태 확인 페이지](http://127.0.0.1:8000/health)를 엽니다.

## 시연 순서

1. 여행 옵션에서 출발일과 마지막 날을 같은 미래 날짜로 선택합니다. 채팅창 위의 자동차 당일치기 예시를 누르거나 아래 요청을 보냅니다.

   > 제주빅데이터센터에서 자동차로 출발해 한림공원과 협재해수욕장을 각각 60분씩 둘러보고 다시 센터로 돌아오는 일정을 짜 주세요. 방문 전에 확인할 시설과 동선도 알려 주세요.

2. 지도에서 이동 경로를 확인하고, 일정표에서 각 장소의 체류시간과 대표 사진, 방문 전 확인사항을 살펴봅니다. 장소명을 누르면 상세 정보를 볼 수 있습니다.
3. 채팅에서 “협재해수욕장 체류시간을 30분으로 줄여 주세요”라고 요청해 일정이 갱신되는지 확인합니다.
4. **전체 일정 PDF 다운로드**를 눌러 바뀐 일정이 파일에 반영됐는지 확인합니다.

## 구현과 데이터

React와 Vite로 화면을 구성하고, FastAPI 백엔드에서 LangChain Agent가 관광지 DB와 교통 도구를 조회합니다. 백엔드는 최종 일정을 검증하면서 방문 시간, 필수 접근 조건과 조회된 이동 경로가 요청과 일치하는지 확인합니다.

관광지와 접근성 자료는 제주데이터허브와 공공데이터포털 자료를 가공해 사용합니다. 데이터와 사진의 세부 출처는 [원본 데이터 명세](docs/raw-data.md)와 [장소별 사진 출처](docs/place-photo-sources.md)에 정리했습니다.
