# 프론트 입력·요약 화면

검증일: 2026-11-09

## 1. 구현 범위

- 기본 출발지는 제주빅데이터센터이며, 출발지 이름을 변경할 수 있습니다.
- 여행 종류 카드를 누르면 조건 입력 화면으로 이동합니다.
- 이동수단, 날짜·시간, 필수 이용 조건, 휴식 시간, 출발지 귀환 여부를 입력합니다.
- 입력 검사 후 요약 화면을 표시하며, 조건 수정 시 입력값을 유지합니다.

## 2. 개발 실행

개발 확인 환경은 Windows, Node.js 24, npm 11입니다.
프로젝트 루트에서 실행합니다.

```cmd
cd frontend
npm ci
npm run dev
```

터미널에 표시되는 Local 주소를 브라우저에서 엽니다.

## 3. 패키지 관리

- 프론트 의존성은 package.json과 package-lock.json으로 공유합니다.
- node_modules와 dist는 Git에서 제외합니다.
- ESLint 하위 패키지 취약점 대응으로 overrides.eslint.minimatch를 11.0.3으로 지정했습니다.
- 해당 override는 임시 조치이며, ESLint 의존성을 갱신할 때 재검토합니다.

## 4. 검증

frontend 폴더에서 실행합니다.

```cmd
npm run lint && npm run build
```

2026-11-09 기준 코드 검사와 빌드가 통과했습니다.
다음 항목은 브라우저에서 수동으로 확인했습니다.

- 여행 종류 선택에 따른 화면 전환과 이동수단 선택.
- 접근 조건 다중 선택·해제와 이전 화면 이동 후 입력값 유지.
- 필수 입력 누락, 잘못된 시간, 전체 여행 시간 이상의 휴식 시간 차단.
- 요약 화면 표시와 조건 수정 후 변경 내용 반영.

## 5. 아직 연결하지 않은 기능

- 출발지의 실제 장소 검색과 좌표 확정.
- Agent를 통한 장소 검색·접근 조건 대조·일정 생성.
- 실제 여행 일정표와 지도·이동 경로 표시.

현재 요약 화면은 사용자가 입력한 조건을 보여줍니다.
장소의 접근성이나 일정의 실행 가능성을 검증한 결과는 아닙니다.
