# 프론트 여행 조건 입력·요약·지도

검증일: 2026-11-09

## 1. 구현 범위

| 기능 | 구현 내용 |
|---|---|
| 여행 종류 선택 | 카드를 클릭하면 조건 입력 화면으로 이동합니다. |
| 여행 조건 입력 | 이동수단, 날짜·시간, 필수 이용 조건, 휴식 시간, 출발지 귀환 여부를 입력합니다. |
| 조건 검사·요약 | 필수 입력과 시간 조건을 검사하고 요약 화면을 표시합니다. 조건 수정 시 입력값을 유지합니다. |
| 출발지 검색 | 카카오 장소 검색으로 제주 지역의 후보를 최대 5개 표시하고, 선택한 장소를 지도에 표시합니다. |
| 출발지 확정 | 확정 버튼을 누르면 장소 ID·이름·주소·위도·경도를 여행 조건에 저장합니다. |

기본 출발지 이름은 제주빅데이터센터입니다.
현재 좌표는 지도 검색 결과에서 장소를 선택하고 확정해야 저장됩니다.

여행 날짜·시간 등을 수정해도 확정한 출발지는 유지됩니다.
출발지 이름을 직접 변경하면 이전 장소와 좌표 선택은 해제됩니다.
여행 종류·입력 조건·현재 화면·확정한 출발지·추가 요청 내역은
sessionStorage에 자동 저장하며, 같은 탭에서 새로고침하면 복원합니다.
저장본이 없거나 저장 형식·버전이 맞지 않으면 기본 상태로 시작합니다.

## 2. 개발 실행·지도 설정

개발 확인 환경은 Windows, Node.js 24, npm 11입니다.
프로젝트 루트에서 실행합니다.

```cmd
cd frontend
npm ci
npm run dev
```

지도 설정은 다음과 같습니다.

| 항목 | 설정 |
|---|---|
| 로컬 환경변수 파일 | frontend/.env.local |
| 환경변수 이름 | VITE_KAKAO_MAP_KEY |
| 키 종류 | 카카오 지도 SDK용 JavaScript 키 |
| 등록한 SDK 도메인 | http://localhost:5173 |
| 개발 서버 | 5173 포트를 사용하며, 사용 중이면 실행을 중단합니다. |

.env.local에 실제 JavaScript 키를 설정합니다.
환경변수를 변경하면 개발 서버를 재시작합니다.

.env.local은 Git에서 제외하고, .env.example에는 변수 이름만 공유합니다.
지도용 JavaScript 키는 브라우저에서 사용합니다.
교통·LLM API 키는 프론트 환경변수에 넣지 않습니다.

## 3. 패키지·코드 관리

- 프론트 의존성은 package.json과 package-lock.json으로 공유합니다.
- node_modules, dist, .env.local은 Git에서 제외합니다.
- ESLint 하위 패키지 취약점 대응으로 overrides.eslint.minimatch를 11.0.3으로 지정했습니다. 의존성 갱신 시 재검토합니다.

| 파일 | 역할 |
|---|---|
| src/App.jsx | 여행 조건과 확정한 출발지 상태를 관리합니다. |
| src/TripSummary.jsx | 여행 조건·출발지 주소를 표시하고 지도에 선택 함수를 전달합니다. |
| src/OriginMap.jsx | 장소 검색, 마커 표시, 출발지 확정을 처리합니다. |
| src/services/kakaoMaps.js | 지도 SDK 로딩과 연결 실패·시간 초과를 처리합니다. |
| src/services/travelSession.js | 상태의 저장·복원과 저장 형식 검사를 처리합니다. |

좌표 필드는 latitude가 위도, longitude가 경도입니다.
카카오 검색 응답의 y를 위도, x를 경도로 변환합니다.

## 4. 검증

frontend 폴더에서 실행합니다.

```cmd
npm run lint && npm run build
```

2026-11-09 기준 lint와 빌드가 통과했습니다.
다음 항목은 개발자가 브라우저에서 수동으로 확인했습니다.

같은 탭에서 새로고침했을 때 여행 종류, 입력 조건, 요약 화면,
확정한 출발지와 추가 요청 내역이 복원되는 것도 수동으로 확인했습니다.

- 여행 종류·이동수단 선택과 화면 전환.
- 필수 입력·시간·휴식 조건 검사와 요약 화면 반영.
- 장소 검색 결과 선택에 따른 지도 마커 표시.
- 출발지 확정 후 요약의 이름·주소 변경.
- 조건 수정 후 출발지 유지와 이름 직접 변경 시 이전 선택 해제.

## 5. 남은 연동

| 항목 | 남은 작업 |
|---|---|
| 기본 출발지 | 센터 위치를 검증하고 초기 출발지 좌표로 자동 설정합니다. |
| 지도 복원 | 요약 화면에 다시 진입했을 때 확정한 출발지의 지도·마커를 자동으로 표시합니다. |
| Agent·일정 | 여행 조건을 백엔드에 전달하고 생성된 일정표와 여행지를 표시합니다. |
| 이동 경로 | 자동차·대중교통·도보 도구의 결과를 받아 지도와 이동 안내에 연결합니다. |

현재 지도는 출발지 선택용입니다.
지도 검색 결과나 경로의 존재만으로 이동약자의 통행 가능 여부를 판단하지 않습니다.

사용자 추가 요청 기능은 [사용자 요청 대화창](travel-chat.md)을 참고합니다.
