## 실험 방법
- 실행: `python -B -m scripts.evaluate_chat_agent --label baseline-v2`
- 필수 조건 H1~H8은 [0001](0001-chat-agent-baseline-eval.md)과 같다. H9: 전달된 일정에 방문 0곳인 일차가 있으면 실패.
- 품질 채점표 R1~R6(사람 채점), 과정 지표, 데이터 충족도, 하루 방문 1곳 이하 일차 수는 기록만 한다.
- 산출물: `outputs/chat_eval/20261111-1234_baseline-v2/` (`runs.jsonl`, `summary.csv`, `report.md`)

## 결과 채택 기준
- 27번 모두 기록이 남으면 기준선으로 채택한다. 실행 오류는 실패한 실행으로 센다.
- 2026-11-11 0002 결과 확인 후 변경: 처음 기준은 "모든 실행이 오류 없이 기록됨"이었다. AI 답 형식 오류도 실제로 일어나는 실패라 측정 결과로 본다 (사용자 결정).
- 기준선 측정이라 점수 기준은 두지 않는다.

## 한계
- 요청 9개 × 3번이라 요청별 통과 수의 변동이 크다 (같은 요청 6개의 요청별 통과 수가 0001과 다름).
- 품질 채점표 R1~R6은 아직 채점하지 않았다.
- 하루 방문 1곳 이하 일정은 실패로 보지 않는다.
- C05·C06 숙소 주소는 시청 주소를 빌려 썼고, AI가 실제 숙박시설이 아니라고 판단할 수 있다 (C06 1회차).
- 데이터 충족도는 DB 칸 기준이며, Agent가 장소 설명 글로 확인한 접근성은 반영하지 않는다.
