# 0010. 여행 기간 축소와 숙소 선택 취소 검증

검증일: 2026-11-18

기간 축소·숙소 선택 취소·고정 방문일 충돌을 연속 대화로 검증했습니다.
저장된 API 응답과 조회 기록을 검토했고, 당일 축소와 새로고침 복원은 사용자에게 화면 확인을 받았습니다.

작업 브랜치는 `test/chat-period-shortening`입니다.
실제 실행 기록의 기준 커밋은 `f1e617f`이며 커밋 전 작업 변경이 있는 상태였습니다.
각 실행 사이에 설명 검사와 질문 지침을 보완했으므로 같은 코드 버전의 반복 실행으로 집계하지 않습니다.

────────────────────────────────────────

## 1. 평가 범위

정의 파일은 [chat_period_shortening_cases.json](../../scripts/eval_cases/chat_period_shortening_cases.json)입니다.
후속 요청에서는 옵션을 미리 변경하지 않고 자연어 메시지만 보냅니다.

| 사례 | 단계 | 확인할 내용 |
|---|---:|---|
| PS01 | 2 | 숙소가 선택된 1박 2일을 숙박 없는 당일로 줄입니다. |
| PS02 | 2 | 이틀의 관광 조건을 유지하고 숙소 선택만 취소합니다. |
| PS03 | 3 | 고정 방문일과의 충돌을 질문하고, 사용자 동의 후 기간과 숙박일을 줄입니다. |

여행일은 2026-11-20~22, 날짜 해석 기준일은 2026-11-18입니다.
자동차·센터 출발 및 마지막 날 귀환·매일 09:00~19:00·장소별 60분 방문을 사용했습니다.
보조기구 미사용과 필수 시설 없음 조건입니다.

초기 숙소는 이전 실제 조회 기록의 제주신라호텔 이름·주소·좌표를 선택값으로 지정했습니다.
이번 사례에서는 주변 숙소 후보 검색과 예약을 검증하지 않습니다.

PS01 첫 단계의 `partial_plan`은 2일차에 관광지 방문이 없기 때문입니다.
호텔→센터 귀환 이동까지 없어도 된다는 의미는 아닙니다.

────────────────────────────────────────

## 2. 발견한 오류와 보완

| 발견한 문제 | 보완 |
|---|---|
| PS01의 정상 첫 응답을 귀환 오류로 판정함 | “2일차를 제거했습니다”의 범위 밖 일차를 현재 귀환 일차로 읽지 않도록 설명 검사를 보완했습니다. |
| PS03의 충돌 질문에 기존 일정을 다시 반환함 | 질문은 `plan: null`로 반환하고 현재 옵션을 유지하도록 시스템 지침과 응답 필드 설명을 보완했습니다. |
| PS03의 잘못된 도착 시각 설명이 자동 통과함 | 출발지 이름 앞뒤에 시각을 쓰는 명시적인 도착 표현도 최종 귀환 시각과 대조합니다. |

PS01 첫 응답의 일정과 10:40 귀환은 맞았으나,
설명에 나온 삭제된 2일차를 귀환 일차로 잘못 해석해 한 번 재생성했습니다.
보완안에서 저장된 첫 응답의 설명 검사가 통과하는 것을 외부 호출 없이 확인했습니다.

최초 PS03의 두 번째 단계는 질문 문구와 기존 옵션을 유지했지만,
이전 일정을 새 `plan`으로 복사하고 상세·경로를 조회하지 않았습니다.
서버가 이를 거부한 뒤 재생성에서도 시간 계산 오류가 남아 HTTP 502를 반환했습니다.

질문 지침을 보완한 다음 실행에서는 세 단계가 자동 통과했지만,
최종 답변의 센터 도착은 11:37, 시간표는 11:25였습니다.
도착 표현 검사를 추가한 뒤 저장된 이 응답을 오류로 검출했습니다.
해당 중간 실행을 최종 정상 결과로 취급하지 않습니다.

시간·경로·상세 조회 검증과 최대 1회 재생성 제한은 유지했습니다.
질문에서 기존 일정을 보존하는 처리는 기존 `plan: null` 응답 연결을 사용합니다.

## 3. 최종 확인 결과

| 사례 | 검토한 최종 결과 |
|---|---|
| PS01 | 당일·숙박 불필요·빈 숙소 선택으로 변경됐습니다. 호텔 이동과 2일차를 제거하고 한라수목원 60분 및 센터 왕복을 유지했습니다. 최종 귀환은 10:40입니다. |
| PS02 | 이틀의 방문일과 각 60분을 유지했습니다. 숙소 상태는 미정, 선택은 빈 목록으로 바뀌었고 호텔 도착·출발 이동만 제외했습니다. 센터 출발과 마지막 날 귀환은 유지했습니다. |
| 마지막 PS03 | 질문에서는 3일 조건·두 숙박일과 기존 일정을 유지했습니다. 동의 후 첫 숙박일만 남기고 셋째 날 해변 방문을 제거했습니다. 답변과 시간표의 최종 귀환은 모두 11:24입니다. |

PS01의 축소 단계와 PS02의 초기 생성에는 각각 재생성이 한 번 있었습니다.
마지막 PS03은 초기 생성의 시간 계산 오류를 한 번 수정했습니다.
마지막 PS03의 충돌 질문과 축소 단계는 각각 첫 시도에 응답했습니다.
충돌 질문에서는 모델 1회·도구 0회와 `plan: null`을 기록했습니다.

자동 검사는 기존 1,055개에 삭제 일차 검사 9개와 도착 표현 검사 10개를 추가해
Python 전체 1,074개가 통과했습니다. `git diff --check`도 통과했습니다.

브라우저에서는 새 1박 2일 일정을 만든 뒤 2일차를 선택한 상태에서 당일로 줄였습니다.
마지막 날 변경, 숙소 선택·호텔 이동·2일차 제거,
한라수목원 60분과 센터 왕복 표시, 답변 시각 일치 및 새로고침 복원을 사용자에게 확인받았습니다.
이 화면 확인의 원본 HTTP 응답과 구체적인 귀환 시각은 별도로 수집하지 않았습니다.

## 5. 확인하지 않은 범위

PS02 숙소 취소와 PS03 충돌 질문·동의 후 축소의 브라우저 화면은 이번 수동 확인 범위에 포함하지 않습니다.
실제 응답과 대화 상태 연결은 저장된 API 기록으로 확인했습니다.

각 사례의 대표 실행을 검토한 결과이며 반복 성공률이나 성능 개선율을 산출하지 않았습니다.
실행마다 코드와 교통 조회값이 달라 처리 시간을 직접 비교하지 않습니다.

설명 검사는 명시적인 일차·시각·출발지 표현 범위에 적용합니다.
모호한 표현과 모든 자연어 사실관계를 판정하는 기능은 아니므로 내용 검토가 계속 필요합니다.
