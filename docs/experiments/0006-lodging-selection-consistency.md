## 1. 발견한 오류와 처리

| 문제 | 확인한 원인과 보완 |
|---|---|
| 선택한 숙소를 다시 검색해 위치를 찾지 못했다고 안내함 | 지시문 보완 뒤에도 불필요한 외부 검색이 남았습니다. 현재 요청의 선택 좌표를 반환하는 요청별 도구를 연결했습니다. |
| 새 숙소 변경 시 재생성이 기존 조건 변경으로 거절됨 | 첫 시도에서 거절된 숙소까지 확정 조건으로 고정했습니다. 해당 숙박일만 재확인 대상으로 두고 다른 숙박일과 여행 조건은 유지합니다. |
| ‘숙소를 신라호텔로 변경’이 조회 성공 후에도 거절됨 | 두 시도 모두 제주신라호텔의 이름·좌표를 정상 조회했지만 사용자 문장에 전체 이름이 없었습니다. 알려진 제주 행정구역 접두사만 생략한 구체적 상호를 제한적으로 허용했습니다. |

선택 좌표 재사용 응답은 `source: selected_lodging`·`lookup_performed: false`로 표시합니다.
새 숙소와 다른 숙박일의 선택 근거로 재사용하지 않으며, 새 조회가 필요하면 선택 숙소용 도구의 `refresh: true`를 사용합니다.
지역명 별칭도 이번 조회 키워드와 반환 상호·좌표가 일치해야 합니다.
일반 명칭·일부 상호·다른 지역 상호는 별칭으로 추정하지 않으며 이전 숙소 좌표를 새 숙소 좌표로 사용하지 않습니다.
