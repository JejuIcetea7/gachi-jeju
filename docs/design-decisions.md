# 디자인 적용 임의 결정 목록

확정 시안(같이 가는 제주 화면 시안)을 React 화면에 옮기면서 사용자와 상의하지 않고 정한 내용이다. 확인되면 상태를 `확인`으로 바꾼다.

## 사용자와 정한 것 (참고)

- 사이드바는 화면 대부분을 덮고, 왼쪽 경계로 너비를 조절한다.
- 일정이 새로 생기거나 바뀌면 사이드바를 자동으로 연다.
- 일정표는 세로 타임라인 카드로 바꾸고, 지도 위에 방문지 요약 줄을 둔다. 카드에 사진은 넣지 않는다.
- 글꼴은 Noto Sans KR(Google Fonts 링크), 아이콘은 SVG를 직접 넣는다.
- 이동 보조기구·접근 조건·여행 종류 선택지는 같은 버튼 모양으로 맞추고, "2박 3일"은 꾸밈 없는 글자로 표시한다.

## 임의 결정

| 1 | 주 색을 시안의 #E65C00 대신 #C74E00으로 쓴다. #E65C00은 테두리·지도 표시 같은 장식에만 쓴다. | #E65C00은 흰 배경에서 글자 대비가 3.6:1로 기준(4.5:1)에 못 미친다. | 미확인 |
| 2 | 이동수단·이동 보조기구를 목록 상자에서 버튼으로 바꾸고, 선택된 버튼을 다시 누르면 미선택이 된다. | 목록 상자의 "미선택"을 버튼에서 표현하는 방법. 서버에 보내는 값은 같다. | 미확인 |
| 3 | 접근 조건·여행 종류는 실제 체크박스를 숨겨 두고 겉모양만 버튼으로 꾸민다. | 키보드·화면 낭독기 동작을 유지한다. | 미확인 |
| 4 | 사이드바가 열려도 메인 화면을 어둡게 가리지 않는다. 왼쪽에 보이는 부분은 계속 누를 수 있다. | 너비를 줄여 대화와 지도를 함께 보는 쓰임을 막지 않는다. | 미확인 |
| 5 | 사이드바 기본 너비는 화면의 60%(최대 880px), 최소 420px, 왼쪽 56px는 항상 남긴다. 직접 조절한 너비만 저장한다. | 처음 값(화면의 92%)이 화면에 가득 차 보기 불편하다는 의견. 옆 패널에 흔히 쓰는 폭(화면 절반 안팎, 900px 전후)에 맞췄다. | 미확인 |
| 6 | 사이드바 열림 상태는 저장하지 않는다. 새로고침으로 복원한 일정에서는 자동으로 열지 않는다. | 세션 저장 구조를 바꾸지 않는다. 새로고침마다 화면을 덮지 않는다. | 미확인 |
| 7 | "지도·일정 열기" 배너는 마지막 메시지가 답변이고 일정이 있을 때만 대화 기록 아래에 표시한다. | 요청 대기 중에 배너가 사용자 메시지 아래에 붙지 않게 한다. | 미확인 |
| 8 | 헤더 버튼 문구는 열림 상태에 따라 "지도·일정 보기" / "지도·일정 닫기"로 바꾼다. | 같은 버튼으로 열고 닫는다. | 미확인 |
| 9 | 대화 기록 영역은 최대 높이(화면 높이의 약 56%)를 두고 안에서 스크롤한다. | 새 메시지에 맞춰 아래로 따라가는 기존 동작을 유지한다. | 미확인 |
| 10 | 문구 변경: 대화 시작 전 "왼쪽 옵션은…" → "위의 옵션은…", 사이드바 빈 상태 → "대화로 일정을 먼저 만들어 주세요." 안내 | 배치가 바뀌었고, 일정 생성 전 안내가 필요하다. | 미확인 |
| 11 | "공간이 좁으면 좌우로 스크롤해 주세요" 안내 문구를 지운다. | 지도와 일정표가 세로로 놓여 좌우 스크롤이 없어졌다. | 미확인 |
| 12 | 일정표의 "N일차" 제목과 "방문" 표시는 알약 모양이 아닌 글자로 표시한다. "여행지 자료 등록" 배지만 알약 모양으로 둔다. | "2박 3일"을 꾸밈 없이 바꾼 요청과 맞춘다. | 미확인 |
| 13 | 지도 경로선 색(자동차 파랑, 도보 초록, 대중교통 주황)은 바꾸지 않는다. | 지도 범례 문구가 색 이름을 쓴다. | 미확인 |
| 14 | 한국어는 단어 단위로 줄바꿈한다(`word-break: keep-all`). | 휴대폰 폭에서 "됩니/다"처럼 단어가 끊겼다. | 미확인 |
| 15 | 600px 이하에서는 말풍선 옆 아이콘을 숨긴다. | 좁은 화면에서 본문 폭을 확보한다. | 미확인 |
| 16 | 3칸 너비 계산(`frontend/src/services/workspacePanels.js`)과 그 테스트는 더 이상 쓰지 않지만 지우지 않는다. | 삭제는 따로 확인받는다. | 미확인 |
| 17 | 메인 화면과 헤더의 내용 폭을 최대 1120px로 둔다(1440px 화면에서 좌우 여백 약 160px). | 처음 값(1400px)이 가로로 넓어 이질감이 든다는 의견. 일반 웹 본문에 흔히 쓰는 폭(1100~1200px)에 맞췄다. | 미확인 |
| 18 | 이동 보조기구·접근 조건·여행 종류 버튼만 높이 48→40px, 글자 15→14px, 아이콘 20→18px로 줄인다. 이동수단 버튼은 그대로 둔다. | 버튼이 너무 크다는 의견. 높이 40px는 권장 터치 크기(44px)보다 조금 작지만 최소 기준(24px)은 넘는다. | 미확인 |
